# Fontit

## Great Vibes

`great-vibes-latin.woff2` — Great Vibes, latin-subset, 42 kB.
Lisenssi: SIL Open Font License 1.1, ks. `OFL-GreatVibes.txt`.

Fontti on **repossa**, ei CDN:ssä. Syy on sama kuin miksi julisteen
README varoittaa Impactista: jos otsikkofontti haetaan muualta tai
oletetaan käyttäjän koneelta, se puuttuu joltakulta ja sivu näyttää
väärältä. Skriptifontin kohdalla varajärjestelmä on erityisen ruma —
`cursive` on eri fontti joka koneella.

Subset on vain latin. Se kattaa ä:n ja ö:n (U+00E4, U+00F6), eli
"Eipä Vissiin!" renderöityy oikein. Jos sivulle joskus tulee kyrillistä
tai kreikkaa, hae laajempi subset osoitteesta
<https://fonts.google.com/specimen/Great+Vibes>.
